# https://crestongetz.github.io/

## Overview
This GitHub page is an ePortfolio showcasing my capstone projects to demonstrate the skills I have built over the past four years at SNHU. My time in the computer science program at SNHU has significantly transformed my goals, values, and technical competency.

## Repository Files
- [narratives](https://github.com/crestongetz/crestongetz.github.io/tree/main/narratives)
  | directory contaning all project narratives as Word documents.
- [artifacts](https://github.com/crestongetz/crestongetz.github.io/tree/main/artifacts)
  | directory contaning all artifacts/projects in zip files. These have the original and enhanced code in them. See links below in the artifacts section to learn how to run the code.
- [index.html](https://github.com/crestongetz/crestongetz.github.io/blob/main/index.html)
  | main HTML file for the home page.

- [algorithms-narrative.html](https://github.com/crestongetz/crestongetz.github.io/blob/main/algorithms-narrative.html)
  | HTML file contaning the algorithms & data structures narrative as a webpage.

  | HTML file contaning the software design and engineering narrative as a webpage.
